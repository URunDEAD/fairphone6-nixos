# Patch series for mailing-list upstreams

Mail-ready `git format-patch` series for upstreams that take patches by email.
**None of these have been sent yet.**

- `linux/` — Linux kernel series (one directory per topic, with cover letter and
  suggested `To:`/`Cc:` in `to-cc.txt`). They carry `Assisted-by:` and **no
  `Signed-off-by:` yet**: the author still has to review them and add a sign-off
  (Developer Certificate of Origin) before sending.
- `ofono/` — oFono series (provisioning database path).

Fix branches for projects hosted on GitHub, GitLab and Forgejo are published as
`fp6/*` branches in forks/mirrors under https://github.com/URunDEAD — see
`CONTRIBUTING-UPSTREAM.md` for the full list and status.
