# Task: fp6-bugreport — one-tap diagnostics bundle (Rust)
A tool to collect a privacy-safe diagnostics bundle for debugging this phone port: system version (/etc/fp6-release), uptime, failed units, recent journal (with configurable time window), kernel log, coredump list (not cores), battery/thermal state, modem/oFono state (no IMEI/ICCID/IMSI/phone numbers), network state (mask MACs/IPs/SSIDs), audio (wpctl status), display/GPU errors, app-ready/zram/oom stats, storage usage. Strong redaction: a reusable redaction module with unit tests (phone numbers in many formats incl. +40/07xx and +999 test numbers, IMEI/ICCID/IMSI, MAC, IPv4/IPv6, SSIDs/BSSIDs, email addresses, GPS coordinates, NetBird/WireGuard keys, passwords/tokens in key=value lines). Output: a tar.zst in ~/Documents/Bug reports/ (0600) plus a summary.txt; a Lomiri app/Settings entry "Create bug report" with a preview of what is included and per-section toggles, and a quick-settings/power-menu shortcut idea; CLI fp6-bugreport with --since and --sections; also a "capture now" mode for intermittent bugs (e.g. text rendering glitches) that additionally saves a screenshot via the existing screenshot D-Bus API if available (document the interface you assume). Root-only data (dmesg, some journals) via a small polkit-guarded helper.
Context: target is the Fairphone 6 running aarch64 NixOS (Mobile NixOS) with the Lomiri shell (Ubuntu Touch UI): Qt 5.15 + Lomiri UI Toolkit 1.3 (Suru look) QML apps, systemd *user* services, D-Bus IPC, PipeWire audio, Maliit on-screen keyboard. New code in Rust (stable, no unsafe unless justified). UITK 1.3 notes: Label has no topPadding/bottomPadding (use margins); GSettings keys must not use ai/ax types. Deliver in this git repo, committing in small steps: the Rust crate(s), QML UI (must render offscreen with QT_QPA_PLATFORM=offscreen for previews; save preview PNGs under previews/), a Nix `package.nix` (rustPlatform.buildRustPackage) and `module.nix` (NixOS module with an enable option under hardware.fairphone6.*, user service, desktop file with X-Lomiri-Touch=true), tests (cargo test must pass on this x86_64 laptop; export NIX_PATH=nixpkgs=channel:nixos-unstable for nix-build checks), DESIGN.md and README.md (incl. a manual test checklist for the real phone), and finish with FINAL_REPORT.md. No telemetry, privacy by default, synthetic data only in tests, do not access any phone or remote host beyond fetching sources/crates.
