# Task: CallKit-style integration for internet calls (Rust)
Design and implement a system service com.fairphone6.Calls1 that lets third-party VoIP/messenger apps (native Linux apps now; Waydroid/Android ConnectionService bridging documented as phase 2) report incoming/outgoing calls so they get the same treatment as cellular calls: full-screen incoming call UI over the lock screen, ringtone + vibration that respect Do Not Disturb rules, call history entries, audio routing (earpiece/speaker/Bluetooth headset) and proximity screen-off during the call, "end call"/"mute" controls, and call-waiting conflicts with cellular calls.
Study: Apple CallKit concepts, Android ConnectionService/Telecom, Telepathy (Lomiri telephony-service is Telepathy-based: research whether registering a Telepathy connection manager for VoIP apps is the cleanest way to reuse the existing dialer/approver UI, vs a separate UI), and the existing phone stack in this project: oFono + lomiri-telephony-service + the DND daemon fp6-notifyd (com.fairphone6 notifications/DND; ShouldAlert API) — describe assumptions where you cannot see the code.
Deliver: the Rust service with a small client library + example client (`fp6-voip-demo` that simulates an incoming call), an incoming-call QML screen prototype (offscreen previews), a DESIGN.md comparing approaches and recommending one, tests (state machine: ringing/answered/held/ended, conflicts with a simulated cellular call, DND decisions) and a phone test plan.
Context: target is the Fairphone 6 running aarch64 NixOS (Mobile NixOS) with the Lomiri shell (Ubuntu Touch UI): Qt 5.15 + Lomiri UI Toolkit 1.3 (Suru look) QML apps, systemd *user* services, D-Bus IPC, PipeWire audio, Maliit on-screen keyboard. New code in Rust (stable, no unsafe unless justified). UITK 1.3 notes: Label has no topPadding/bottomPadding (use margins); GSettings keys must not use ai/ax types. Deliver in this git repo, committing in small steps: the Rust crate(s), QML UI (must render offscreen with QT_QPA_PLATFORM=offscreen for previews; save preview PNGs under previews/), a Nix `package.nix` (rustPlatform.buildRustPackage) and `module.nix` (NixOS module with an enable option under hardware.fairphone6.*, user service, desktop file with X-Lomiri-Touch=true), tests (cargo test must pass on this x86_64 laptop; export NIX_PATH=nixpkgs=channel:nixos-unstable for nix-build checks), DESIGN.md and README.md (incl. a manual test checklist for the real phone), and finish with FINAL_REPORT.md. No telemetry, privacy by default, synthetic data only in tests, do not access any phone or remote host beyond fetching sources/crates.
