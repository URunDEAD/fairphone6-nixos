# Calls1 wire API (experimental v1)

Session bus name and interface `com.fairphone6.Calls1`; object `/com/fairphone6/Calls1`. Rust clients use `fp6_callkit::client::CallsProxy`. Standard D-Bus introspection is generated by zbus. `t` = unsigned 64-bit, `s` = string, `b` = boolean. Methods return ordinary D-Bus errors for authorization, malformed metadata, invalid state, focus conflicts or stale commands. Call IDs and revisions are valid only for the current service owner.

| Method | Input → output | Access |
|---|---|---|
| ReportIncoming | `ss` app, display name → `t` id | Provider; binds unique sender |
| ReportOutgoing | `ss` app, display name → `t` id | Provider; requires cellular Idle and focus |
| ReportConnected | `t` id → empty | Owner of a Dialing call |
| ReportEnded | `t` id → empty | Owner; idempotent while retained |
| Calls | empty → `s` JSON array | Own calls only |
| Commands | `t` id → `s` JSON command or `null` | Owner; non-consuming, retryable |
| Complete | `ttb` id, command serial, success → empty | Owner; before deadline |
| Snapshot | empty → `s` JSON snapshot | Current CallsShell1 owner |
| Control | `ts` id, JSON action → `t` command serial | Current CallsShell1 owner |
| History | empty → `s` JSON array | Current CallsShell1 owner |
| ClearHistory | empty → empty | Current CallsShell1 owner |
| SetProximity | `b` near → empty | Current CallsShell1 owner |
| Changed (signal) | `t` revision | Public; contains no identity |

Action JSON: `{"kind":"answer"}`, `{"kind":"hold"}`, `{"kind":"resume"}`, `{"kind":"end"}`, `{"kind":"mute","value":true}`, `{"kind":"route","value":"speaker"}`. Routes: `earpiece`, `speaker`, `bluetooth`. Unsupported fields/variants do not grant capabilities. Treat JSON strings as data; never interpolate them into commands or rich text.

A command is `{"serial":1,"action":{"kind":"answer"},"deadline":5}`. Deadlines and call timestamps are seconds from the broker's monotonic start, not wall-clock timestamps. Execute media/signalling work before Complete; `false` means the state change was not applied. Do not acknowledge a route your media engine cannot use. Read Calls even when Commands is null to observe forced Ended states. Subscribe to Changed before the initial snapshot, and reconcile on every signal; the demo polls every 100 ms instead. Repeated Commands can return the same serial, so provider execution must be idempotent. Treat an unknown Complete reply as uncertain and reconcile instead of repeating a non-idempotent media operation.

Call JSON fields: `id`, `app`, `display_name`, `incoming`, `state`, `muted`, `route`, `alert`, `created`, `pending`, `reason`, `ended_at`, `answered_at`. Internal sender ownership is never serialized. States: `ringing`, `dialing`, `active`, `held`, `ended`. Snapshot adds `revision`, `cellular` (`unknown`, `idle`, `busy`, `emergency`), `calls`, `effects`, `platform_ready`. Snapshot display names are always `Internet caller`, even while unlocked in this prototype. The caller's own Calls response preserves its supplied display name.

History fields: `id`, `app`, `incoming`, `created`, `answered_at`, `ended`, `reason`. `answered_at: null` distinguishes unanswered calls; otherwise it records the first successful answer/connection, preserving it through hold/resume. Reasons currently include `remote_end`, `local_end`, `cellular_priority`, `provider_disconnected`, `command_timeout`, `no_answer`. History is volatile and capped at 100; it is not a durable delivery queue. A native history adapter should key entries by broker-owner epoch and id, consume promptly, and own its retention/deletion policy.

## Proposed adjacent interfaces

These contracts are **not known existing Fairphone APIs**. Adapt the phone's actual APIs behind them.

- DND: name/interface `com.fairphone6.Notifications1`, path `/com/fairphone6/Notifications1`, `ShouldAlert(s category) -> (b sound, b vibration)`. Category `internet-call`. Timeout 300 ms; failure is silent. No provider-controlled exception flags.
- Platform: name/interface `com.fairphone6.CallsPlatform1`, path `/com/fairphone6/CallsPlatform1`, `Apply(s effects_json, u lease_ms) -> empty`. Lease is 2500 ms; renewed roughly once a second and on effect changes. Timeout 300 ms. Effects fields: `ringing`, `vibrating`, `incoming_ui`, `audio_call` (id or null), `route` (enum or null), `muted`, `screen_off`. Empty/default state releases owned resources. An implementation must authenticate the Calls1 owner, reject unavailable capabilities, replace previous desired state, and release resources when the lease/broker disappears. Late requests must not revive an expired/replaced broker epoch.
- Shell: owns `com.fairphone6.CallsShell1`; no exported methods are required by the broker. It receives snapshots/signals, maps QML intents to Control, and posts proximity readings. For QML `mute`/`unmute`, construct the typed boolean action; for routeRequested use the route action. Only update visual call state from a broker snapshot. Use platform_ready to disclose unavailable phone integration.

The only supplied implementations of adjacent interfaces are explicitly synthetic test/demo fixtures. They neither play audio nor vibrate nor blank any display. The package does not activate these fixtures in a phone session.
