# Task: Unified system share sheet (Rust + QML)
One consistent "Share" panel for all apps, iOS/Android style. Build `fp6-share`: a share sheet UI + D-Bus service com.fairphone6.Share1 (method Share(items: [uris|text|url], mime, source_app) -> shows the sheet) that lists targets from several providers:
- Lomiri content-hub share peers (read the content-hub peer registry the way lomiri-content-hub does; document the files/API you rely on),
- nearby targets: Quick Share devices (D-Bus com.fairphone6.QuickShare1: properties/methods StartDiscovery, Send(target,[uris|text]), signals DeviceFound/Lost), KDE Connect devices (com.fairphone6.KdeConnect1 — read ../kdeconnect/README.md for its API), "Share via link/QR" (com.fairphone6.WebShare1 — ../webshare/README.md),
- actions: Copy, Save to Files (via the xdg-desktop-portal FileChooser SaveFile), Print (if CUPS present, else hidden), Text recognition for images (com.fairphone6.Ocr1 — ../ocr/README.md),
- recent targets / direct share (last 8 people/devices), ordering by recency.
Also provide: an xdg-desktop-portal-compatible entry point so GTK/Qt/Firefox apps can reach it (document: there is no standard Share portal; implement an org.freedesktop.portal.OpenURI-style handler or a desktop-file MIME handler "share" approach — research and pick the most compatible), a content-hub "share" peer so UT apps route into it, and a CLI `fp6-share FILE...`. Robust when a provider service is absent (hide it). Design the provider interface as a trait so more providers can be added. Previews offscreen with mocked providers.
Context: target is the Fairphone 6 running aarch64 NixOS (Mobile NixOS) with the Lomiri shell (Ubuntu Touch UI): Qt 5.15 + Lomiri UI Toolkit 1.3 (Suru look) QML apps, systemd *user* services, D-Bus IPC, PipeWire audio, Maliit on-screen keyboard. New code in Rust (stable, no unsafe unless justified). UITK 1.3 notes: Label has no topPadding/bottomPadding (use margins); GSettings keys must not use ai/ax types. Deliver in this git repo, committing in small steps: the Rust crate(s), QML UI (must render offscreen with QT_QPA_PLATFORM=offscreen for previews; save preview PNGs under previews/), a Nix `package.nix` (rustPlatform.buildRustPackage) and `module.nix` (NixOS module with an enable option under hardware.fairphone6.*, user service, desktop file with X-Lomiri-Touch=true), tests (cargo test must pass on this x86_64 laptop; export NIX_PATH=nixpkgs=channel:nixos-unstable for nix-build checks), DESIGN.md and README.md (incl. a manual test checklist for the real phone), and finish with FINAL_REPORT.md. No telemetry, privacy by default, synthetic data only in tests, do not access any phone or remote host beyond fetching sources/crates.
