# Task: Live captions (Rust)
On-device live captions for any audio playing on the phone (videos, podcasts, voice messages) and optionally the microphone, Android "Live Caption" style: a small floating caption overlay (Lomiri: implement as a normal always-on-top app window first; document what a shell-side overlay would need) that shows rolling text with ~1–2 s latency, draggable/collapsible, opacity setting, and a quick-settings tile hook described for the coordinator. Audio source: PipeWire monitor of the default sink (only while captions are on; must show the existing privacy "in use" indicator semantics — document how), never during phone calls unless the user explicitly enables it.
Reuse the offline dictation engine in ../dictation (read-only reference: Rust, whisper-rs, model catalog with on-demand verified downloads, D-Bus com.fairphone6.Dictation1). Prefer adding a streaming mode (chunked VAD + incremental decoding with overlap) as a library you could later upstream into that crate; keep this project self-contained by depending on a copy/path of the needed pieces. Languages English + Romanian; auto language detection optional. Budget: keep CPU modest (configurable model tiny/base, int8/q5), stop automatically when audio is silent for N minutes, and expose battery-impact notes. Tests: streaming segmentation/merging logic with synthetic PCM and TTS-generated clips (generate locally), and a latency benchmark. No transcripts are stored unless the user saves them.
Context: target is the Fairphone 6 running aarch64 NixOS (Mobile NixOS) with the Lomiri shell (Ubuntu Touch UI): Qt 5.15 + Lomiri UI Toolkit 1.3 (Suru look) QML apps, systemd *user* services, D-Bus IPC, PipeWire audio, Maliit on-screen keyboard. New code in Rust (stable, no unsafe unless justified). UITK 1.3 notes: Label has no topPadding/bottomPadding (use margins); GSettings keys must not use ai/ax types. Deliver in this git repo, committing in small steps: the Rust crate(s), QML UI (must render offscreen with QT_QPA_PLATFORM=offscreen for previews; save preview PNGs under previews/), a Nix `package.nix` (rustPlatform.buildRustPackage) and `module.nix` (NixOS module with an enable option under hardware.fairphone6.*, user service, desktop file with X-Lomiri-Touch=true), tests (cargo test must pass on this x86_64 laptop; export NIX_PATH=nixpkgs=channel:nixos-unstable for nix-build checks), DESIGN.md and README.md (incl. a manual test checklist for the real phone), and finish with FINAL_REPORT.md. No telemetry, privacy by default, synthetic data only in tests, do not access any phone or remote host beyond fetching sources/crates.
