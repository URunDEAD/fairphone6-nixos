# Task: Data saver + smart Wi-Fi/mobile switching (Rust)
A user daemon + system helper for NetworkManager (the phone uses NetworkManager for Wi-Fi and the oFono/ofono-based mobile data; read the NetworkManager D-Bus API and model mobile data as a separate device/connection that can be toggled through a small root helper you define as an interface — the coordinator will wire it to the real oFono data toggle).
Features:
1. Data saver (Android-like): when on mobile data or a metered connection, restrict background traffic for apps that are not in front: per-app allow-list, using cgroup v2 + nftables (socket cgroupv2 matching) on the systemd user slices of apps (apps run as systemd scopes/services named by app id under app.slice / lomiri-app-launch units — design for that and make the matching configurable). Foreground app always allowed; system services (updates, NTP, DNS, VPN, push) handled via an explicit list. Monthly data usage per app (from nftables counters or cgroup socket stats) with a usage page and warning/limit thresholds.
2. Smart switching: Wi-Fi quality monitor (signal, packet loss/latency probes to the gateway and a configurable public endpoint — default to the NetworkManager connectivity check URL, no third-party telemetry) that prefers mobile data when Wi-Fi is "connected but unusable", with hysteresis, never on metered-capped plans unless allowed, and notifications explaining the switch. Also "Wi-Fi on automatically near saved networks" is out of scope (document).
3. Settings page (QML) for data saver, per-app usage and allow-list, smart switching toggle and thresholds; quick-settings tile hook described for the coordinator.
Tests: unit tests for the policy engine and hysteresis with simulated link metrics; nftables rule generation tests (golden files); an integration test in a network namespace if feasible without root (otherwise document a root-only test script).
Context: target is the Fairphone 6 running aarch64 NixOS (Mobile NixOS) with the Lomiri shell (Ubuntu Touch UI): Qt 5.15 + Lomiri UI Toolkit 1.3 (Suru look) QML apps, systemd *user* services, D-Bus IPC, PipeWire audio, Maliit on-screen keyboard. New code in Rust (stable, no unsafe unless justified). UITK 1.3 notes: Label has no topPadding/bottomPadding (use margins); GSettings keys must not use ai/ax types. Deliver in this git repo, committing in small steps: the Rust crate(s), QML UI (must render offscreen with QT_QPA_PLATFORM=offscreen for previews; save preview PNGs under previews/), a Nix `package.nix` (rustPlatform.buildRustPackage) and `module.nix` (NixOS module with an enable option under hardware.fairphone6.*, user service, desktop file with X-Lomiri-Touch=true), tests (cargo test must pass on this x86_64 laptop; export NIX_PATH=nixpkgs=channel:nixos-unstable for nix-build checks), DESIGN.md and README.md (incl. a manual test checklist for the real phone), and finish with FINAL_REPORT.md. No telemetry, privacy by default, synthetic data only in tests, do not access any phone or remote host beyond fetching sources/crates.
